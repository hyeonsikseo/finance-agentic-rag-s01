# 문서 뭉치 안내

## 원본 문서는 이 저장소에 없습니다

보험사, 협회, 은행, 카드사 문서는 대부분 저작권이 그 회사에 있고 "무단 복제·배포 금지"입니다. 금융감독원 자료는 교육 목적 인용은 되지만 다시 나눠 주는 것은 안 됩니다. 수업이라고 예외가 아닙니다. 그래서 원본을 저장소에 넣지 않고, 각자 원 출처에서 내려받습니다. 저장소에는 "무엇을 어디서 받는지"만 들어 있습니다.

예외는 `bundled/` 폴더의 법제처 자료 4건입니다. 공공누리 1유형이라 출처만 표시하면 자유롭게 쓸 수 있습니다. 인용할 때는 "출처: 법제처 국가법령정보센터"를 적습니다.

## 이 폴더에 있는 것

| 파일 | 무엇 |
|---|---|
| `corpus_manifest.csv` | 문서 51건을 어디서 어떤 조건으로 받는지. 유일한 기준입니다 |
| `download_corpus.py` | 내려받는 스크립트 |
| `documents.csv` | 받은 문서를 실제로 열어 보고 잰 카탈로그. 1회차의 지도입니다 |
| `doc_profile.json` | 측정 상세. 파서별 글자 수, 깨진 쪽, 빈 쪽 |
| `constants.yaml` | 세율처럼 법이 정한 값. 이율이나 수수료율은 여기 두지 않습니다 |
| `glossary.md` | 용어집. 고객이 쓰는 말과 문서에 적힌 말의 차이 |
| `bundled/` | 다시 나눠 줄 수 있는 문서 4건 |
| `raw/` | 내려받은 원본. 저장소에는 올라가지 않습니다 |
| `golden/` | 평가 문항 60개. 3회차부터 씁니다 |

## 내려받기

```bash
make download        # 또는 .venv/bin/python data/download_corpus.py
```

약 5분 걸립니다. 몇 건 실패하면 같은 명령을 다시 돌리면 대부분 받아집니다. 계속 실패하면 그 문서만 지정합니다.

```bash
.venv/bin/python data/download_corpus.py --only <doc_id>
```

결과는 `download_report.json` 에 남습니다. 어떤 문서가 왜 실패했는지 적혀 있습니다.

사이트마다 요청 간격을 두고 받습니다. 스크립트에 그렇게 돼 있고, 그 값을 줄이지 않습니다. 수강생 여섯 명이 같은 날 받아도 사이트에 부담이 되지 않는 정도입니다.

## 문서를 인용할 때

- 조항 단위로 짧게 인용하고 출처를 적습니다. 쪽 전체를 캡처하지 않습니다.
- 숫자를 인용할 때는 문서 이름과 시행일(또는 기준일)을 같이 적습니다.
- `bundled/` 밖의 파일은 어떤 형태로도 다시 나눠 주지 않습니다.
