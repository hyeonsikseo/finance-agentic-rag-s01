# 사용자 시나리오와 질문 유형 정의서 (예시)

> 강사가 만든 예시입니다. 이 시스템이 받을 질문을 8가지로 나누고, 유형마다 시스템이 무엇을 해야 하는지 정합니다.
> 예시 질문은 전부 수업 코퍼스에서 실제로 답이 나오는 것입니다. 괄호 안은 골든셋 문항 번호입니다.

## 1. 누가 어떤 상황에서 묻나

| 상황 | 상담사가 치는 질문 | 시스템이 돌려줘야 하는 것 |
|---|---|---|
| 2021년에 대출받은 고객이 기한이익 상실 통지 기한을 묻는다 | "2021년 5월 가입 하나은행 가계대출, 기한이익 상실 통지는 며칠 전까지?" | 2013.7.1 시행 판본 제7조 제2항. "2013.7.1 시행 판본 기준" 표기 |
| 적금을 중간에 해지하면 이자가 얼마인지 묻는다 | "장병내일준비적금 24개월을 7개월에 해지하면 이자율?" | 설명서의 중도해지이율 표에서 값을 뽑아 함수로 계산. 표의 출처 표기 |
| 상품설명서에 요율이 비어 있다 | "하나은행 2014 가계대출 중도상환수수료율?" | "문서에 요율이 비어 있습니다. 계약서를 확인하세요." 답하지 않는다 |
| 상담사가 고객 이름을 같이 친다 | "김○○ 고객님 정기예금 만기 후 이율?" | 이름은 가리고 나머지로 검색. 로그에는 원문 대신 해시 |
| 상품이 아닌 것을 묻는다 | "달 여행 보험료는 얼마예요?" | 근거가 없으므로 답하지 않는다 |

## 2. 질문 유형 8종

| 유형 | 정의 | 예시 | 시스템이 해야 할 것 | 문항 |
|---|---|---|---|---|
| 조항번호형 | 문서와 조항 번호를 대고 내용을 묻는다 | "하나카드 표준약관 제31조의 리볼빙이란?" (S01) | 조항 번호로 정확히 찾는다. 키워드 검색이 강하다 | 8 |
| 상품명조건형 | 상품 이름을 대고 가입 조건이나 한도를 묻는다 | "장병내일준비적금은 산업기능요원도 가입할 수 있나?" (S09) | 상품명으로 문서를 좁힌 뒤 조건을 찾는다 | 6 |
| 표수치형 | 표 안의 숫자를 묻는다 | "iM뱅크 가계대출 1억 5천만원일 때 인지세?" (S20) | 표를 표대로 읽어 행과 열을 맞춘다 | 6 |
| 메타데이터형 | 시행일, 판본, 심의필 같은 시점 조건이 붙는다 | "2013.7.1 시행 판본 기준 통지 기한?" (S15) | 시행일 필터로 판본을 고르고 답에 시점을 적는다 | 5 |
| 복합형 | 조항 여러 개나 약관과 사례를 합쳐야 한다 | "이용한도 감액 통지 방법과 관련 분쟁조정사례?" (S26) | 문서 두 종류를 함께 찾아 종합한다 | 5 |
| 계산형 | 숫자를 계산해야 한다 | "24개월 적금을 7개월에 해지하면 중도해지이자율?" (S31) | 문서에서 요율과 규칙을 뽑고 함수로 계산한다. LLM 은 계산하지 않는다 | 5 |
| 유사상품비교형 | 두 문서나 두 판본을 비교한다 | "2013년 판과 2024년 판의 통지 기한 차이?" (S38) | 두 판본을 모두 찾아 나란히 보여 준다 | 3 |
| 미답변형 | 근거가 없거나 문서에 값이 없다 | "2014 설명서의 중도상환수수료율?" (S40, 빈칸) | 답하지 않고 이유를 말한다 | 2 |

계산형은 따로 15문항이 더 있고, 적대적 문항 5개가 있습니다. 적대적 문항은 시스템 프롬프트를 내놓으라거나, 고객 계좌를 묻거나, 없는 조항을 근거로 우기는 질문입니다. 전부 거절이 정답입니다.

## 3. 유형별로 따로 재는 이유

전체 평균이 올라도 한 유형이 바닥이면 그 질문을 받는 상담사는 못 씁니다. 유형마다 실패하는 지점이 다르기 때문입니다.

| 유형 | 주로 어디서 실패하나 | 어느 회차에서 고치나 |
|---|---|---|
| 조항번호형, 상품명조건형 | 조항 경계를 잘못 잘라 번호가 어긋난다 | 2회차 청킹 |
| 표수치형 | 표를 줄글로 읽어 행과 열이 섞인다 | 2회차 표 파싱 |
| 메타데이터형, 유사상품비교형 | 판본을 못 고르고 최신본만 찾는다 | 4회차 시점 필터 |
| 복합형 | 문서 한 종류만 찾고 멈춘다 | 5회차 재검색 |
| 계산형 | LLM 이 어림잡아 계산한다 | 5회차 계산 툴 |
| 미답변형 | 근거가 없는데도 답을 만든다 | 5회차 거절 정책 |

## 4. 모든 답에 붙는 것

- **근거**: 문서 이름, 조항, 쪽. 상담사가 클릭해서 원문을 볼 수 있어야 합니다.
- **시점**: 시행일 또는 기준일. 심의 유효기간이 지난 문서면 경고를 붙입니다.
- **표시**: "AI 가 생성한 참고 답변이며 실제 계약은 약관·증서가 우선합니다."
- **숫자**: 계산 결과에는 사용한 요율과 규칙의 출처를 적습니다. 세율은 법령 상수라는 것을 따로 적습니다.
