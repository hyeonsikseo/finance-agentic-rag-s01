찾는 데 시간이 많이 걸린다는 이야기가 계속 나오고 있습니다. 특히 신입 상담사들이
어려워합니다.

그게 가능한지 잘 모르겠습니다.

경쟁사 한 곳이 비슷한 걸 했다는 이야기를 들었습니다.

우선 **PoC 를 해 보고** 되겠다 싶으면 정식으로 예산을 올리려고 합니다.
다음 달 중순에 임원 보고가 있어서 그 전에 뭔가 보여 드릴 게 있으면 좋겠습니다.

가능하신지, 그리고 저희가 뭘 준비하면 되는지 알려 주시면 감사하겠습니다.

## 이 메일에서 알 수 있는 것

- 대상 업무는 콜센터 상담사의 약관·상품설명서 조항 조회입니다.
- 문제 인식은 "시간이 오래 걸린다", "신입이 어려워한다"입니다.
- 제약은 "내부망" 하나입니다.
- 일정은 다음 달 중순 임원 보고입니다.
- 순서는 PoC, 예산, 정식 도입입니다.

## 이 메일로는 알 수 없는 것

아래는 물어봐야 나오는 것들입니다. 목록을 그대로 읽으며 묻지는 않습니다. 왜 알아야 하는지를 생각하면서 물어야 다음 질문이 나옵니다.

- 문서는 몇 건이고, 어디에 있고, 누가 갱신하는지
- "오래 걸린다"가 실제로 몇 분인지, 하루 몇 건인지
- 오래 걸리는 이유가 정말 검색 속도인지
- "내부망"이 정확히 무엇을 금지하는지. 외부 API 호출인지, 데이터 반출인지, 둘 다인지
- 상담사가 이 답을 고객에게 그대로 읽어 주는지
- 틀린 답이 나가면 무슨 일이 생기고, 누가 책임지는지
- 개인정보가 질문에 섞여 들어오는지
- 서버와 GPU 가 있는지
- 성공을 어떻게 판정할지
- 이 프로젝트에 반대할 사람이 누구인지
